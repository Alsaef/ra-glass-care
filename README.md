# RA Glass Care — Storefront & Commercial Window Cleaning
**Astoria, Queens, New York City (NYC)**
*Make Your Business Shine!*

A modern, high-converting, luxury-grade service landing page built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
